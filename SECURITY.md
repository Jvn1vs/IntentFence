# Security policy

IntentFence is experimental defense software, not a security guarantee. Do not report adaptive bypass prompts through a public issue when they include real credentials, private data, or a live vulnerable target.

For this initial repository, contact the repository owner privately through GitHub. Include the affected version, minimal reproduction using synthetic data, impact, and suggested mitigation. Remove all real secrets and personal data.

Supported security fixes target the latest main branch. High-risk actions must remain protected by authorization and human confirmation even when the detector reports low risk.
