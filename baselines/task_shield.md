# Task Shield comparison status

No Task Shield result is currently claimed by this repository.

Any future result must use exactly one label:

- `paper-reported`: cited from the paper with its original benchmark configuration;
- `reproduced`: same frozen model, prompt, AgentDojo version, task subset, agent and attack setup;
- `Task-Shield-inspired approximation`: a local LLM consistency judge, never presented as a direct reproduction.

Requests and responses from LLM-based comparisons must be cached with model identifiers and configuration. The core IntentFence result does not depend on this optional baseline.
