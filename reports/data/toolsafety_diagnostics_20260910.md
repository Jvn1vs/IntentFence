## 定义异常已得到进一步解释

对固定快照全部 15569 条逐条检查，结果相互排斥：

| 工具定义状态 | 对话数 |
|---|---:|
| 名称唯一且定义可解析 | 12883 |
| 同名定义重复，但重复项内容完全一致 | 1823 |
| 同名定义内容冲突 | 860 |
| 工具列表含非对象成员 | 2 |
| 其他定义字段不满足结构要求 | 1 |

原审计的 2686 条未解析定义由后四类组成。1823 条完全一致的重复项仅在诊断内对比，原始数据和既有解析器均未更改；是否在未来适配时去重需版本化记录。860 条冲突定义不选择第一个或最后一个来掩盖歧义。

原来的 1698 项未解析前置调用，全部不能被 Python 表达式语法解析。这个结论不等于证明它们在任何调用语言下都无效，也不等于全部仅需补一个引号；当前不猜测修复。

## 对动作位置作更严格的只读筛查

原有 6054 个“工具返回之后有可解析调用”的位置中，4760 个通过以下有限检查：

- 同一对话工具定义可解析，或只包含内容完全相同的重复定义；
- 返回名称与前置调用名称配对；
- 后续调用名称存在于定义中；
- 后续调用提供了 required 中列出的参数名，且参数名都列于 properties。

这些位置分布在 **2873 条对话**：2613 条使用唯一工具定义，260 条只涉及完全一致的重复定义。它们是进一步可用性审核入口，不是已经通过安全标注、许可审查和隔离检查的训练数据。

未通过位置的标记包括：前置调用/返回配对未解决 1065，定义未解决 236，缺 required 参数 16，参数名未列于 properties 21。标记可重叠，不能相加当作独立失败位置数。properties 外参数可能被上游额外属性规则允许，因此此处只作保守分流，不声称完整 JSON Schema 验证失败。

尚未验证参数值类型、嵌套 schema、权限与目标匹配、语义安全、跨 split 近重复，以及逐样本工具来源归属。不得使用“通过名称检查”代替这些条件。

## 小规模语境核对：不继承整段轨迹标签

Codex/AI 完整读取三个符合筛查条件、首个工具返回位置且前四条消息总长不超过 4000 字符的前缀。选择规则为源文件顺序下的前三条，零基 record index 为 4521、4523、4525；不是随机或代表性样本，也没有查看后续返回来判断当前动作。

- 4521：当时可见内容是普通视频元数据，下一步请求字幕。用户目标本身没有明确给出目标 URL，目标绑定仍需核验，不能因为整段后来可能出现有害内容就给此前位置赋攻击标签。
- 4523：可见内容是电影类型统计，随后请求某一年电影清单。用户提出的年份范围更宽，单个中间调用不够证明已满足任务，也不够直接断言动作恶意。
- 4525：工具返回视频链接后，下一步请求预览该链接，属于与用户需求相关的动作结构；没有据此声明权限、安全或最终结果已验证。

本次只记录可用性观察，不生成 Risk/Alignment 真值，不更新 human_verified。三例说明需要基于动作前缀独立审核，不能把整条安全回应训练轨迹的类别广播给所有中间动作。
