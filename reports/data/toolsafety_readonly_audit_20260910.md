## 可用性判断

当前只能认为它提供了值得继续核验的多步工具上下文；不能整包直接并入 IntentFence：

1. 源字段不含本项目五类 Risk 或四类 Task Alignment。直接有害用户请求、一般有害工具返回和间接提示注入必须区分；不能用“安全拒绝”标签自动映射任务对齐。
2. 部分调用存在未转义的嵌套引号。对未解析前置调用的两例完整调用文本检查证实此问题，但不能据两例声称全部 1698 项都由同一错误导致。解析器不执行调用、不作猜测修复、不自动丢弃异常。
3. 来源包含模拟轨迹。保留为源字段可以证明记录内容，却不能证明真实工具执行过。候选提取必须保留原轨迹及位置，避免使用动作之后的返回结果、最终回应或标签作为当前输入。
4. 尚未执行与旧 calibration/Test A/B/C/D 的跨来源近重复排除，也未建立动作、工具、目标家族隔离。对话内多个动作必须同组；训练/验证/校准/测试不能按动作行随机拆分。
5. 数据卡 MIT、上游 Glaive/ToolBench/ToolAlpaca 的仓库级声明及局限见来源调查报告。逐样本工具来源和第三方 API 描述归属尚未对应完成，不能报告完整条款链通过。
